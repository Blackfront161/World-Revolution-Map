# Beiträge zum Atlas

Danke für dein Interesse. Neue Einträge sollen nachvollziehbar, respektvoll und geografisch korrekt sein.

## Mindestangaben

- eindeutiger Titel und präziser Ort
- Kategorie und Startjahr, optional Endjahr
- gültige Längen- und Breitengrade
- neutral formulierter Kurztext
- Erklärung der historischen Bedeutung
- belastbarer weiterführender Quellenlink
- Bildbeschreibung, falls ein Bild verwendet wird

## Redaktionelle Grundsätze

1. Ereignisse nicht romantisieren oder Gewalt verharmlosen.
2. Umstrittene Deutungen als solche kenntlich machen.
3. Betroffene Gruppen möglichst mit ihren Selbstbezeichnungen benennen.
4. Inhalte aus mehreren Perspektiven und anhand seriöser Literatur prüfen.
5. Keine Bilder ohne geklärte Lizenz oder verlässliche Herkunft eintragen.

## Lokale Prüfung

```bash
npm test
node scripts/serve.mjs
```

Danach `http://localhost:4173` öffnen und Suche, Filter, Popups, Mission, Quiz sowie die mobile Darstellung prüfen.
